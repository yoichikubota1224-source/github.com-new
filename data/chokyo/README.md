**文字コードは CP932。** UTF-8 として読むと壊れる。`open(p,'rb').read().decode('cp932')` で読むこと。

SHA-256 は `SHA256SUMS.txt`(`sha256sum -c SHA256SUMS.txt` で検証できる)。

## 列の意味

**坂路(ヘッダ無し・18列)**

```
0:調教場 1:日付(YYYYMMDD) 2:曜日 3:時刻 4:馬名 5:(空) 6:性別 7:年齢 8:クラス 9:調教師
10:4F累計 11:3F累計 12:2F累計 13:1F 14:ラップ1 15:ラップ2 16:ラップ3 17:ラップ4
```

累計と各ハロンラップは整合する(例: 15.8+14.4+13.4+12.8 = 56.4 = 4F累計)。

**ウッド(ヘッダ有り・40列)**

```
0:場所 1:コース 2:回り 3:年月日 4:曜日 5:時刻 6:馬名 7:Ｃ 8:性別 9:年齢 10:収得賞金 11:調教師
12〜21:10F〜1F累計   22〜30:Lap9〜Lap1   31:血統登録番号 32:日付S 33:調教場 34:種牡馬名 35:母馬名 …
```

## 収録範囲(重要)

収録されているのは次の4群だけである。

| 場所 | コース | 本数 |
|---|---|---:|
| 栗東 | 坂路 | 1,906 |
| 美浦 | 坂路 | 1,368 |
| 美浦 | ウッド(D) | 837 |
| 栗東 | ウッド(C) | 593 |

**芝・ポリトラック・プール・障害・地方・外厩、および 栗東DW・美浦南A・北B/C は入っていない。**
これが第5報のカバー率 64.2%(589/918頭)の上限を決めている。欠落分は成績で偏っておらず(3着内 24.0% vs 22.2%)、
純粋に**コースの収録範囲の問題**である。

## 使い方

```bash
python3 scripts/chokyo_baseline.py   # 日×場×コースの馬場差ベースラインを作る
python3 scripts/chokyo_rejoin.py     # 確定結果に結合して再検定
python3 scripts/chokyo_probe.py      # 人気交絡とカバレッジの点検
```

CSVの読み取り元は `scripts/chokyo_baseline.py` の `SP` 定数。中間成果物の置き場は環境変数 `CHOKYO_WORK` で差し替えられる。

## 運用

第5報§8-1のとおり、**毎週この2種を保存し続けること**が次の一手である。
あと3〜4開催日ぶん溜まれば、補正後zの検定(現在 p=0.0996)が結論を出せる水準に届く。
