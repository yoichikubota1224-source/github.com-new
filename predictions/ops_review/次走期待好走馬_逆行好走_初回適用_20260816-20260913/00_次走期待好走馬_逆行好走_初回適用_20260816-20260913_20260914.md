## 1．定義（v1.1・本適用で使用したもの）

| 項目 | 定義 |
|---|---|
| 位置取り | 最終コーナー（4角。無ければ取得できた最後のコーナー）の通過順位。前1/3＝順位≦頭数÷3（切捨て）、後1/3＝順位＞頭数−頭数÷3、その間＝中 |
| 流れ | 5着以内5頭のうち前1/3にいた頭数で判定。0〜1頭＝**差し有利（強）**、2頭＝差し有利、3頭＝前有利、4〜5頭＝**前有利（強）** |
| 逆行 | 差し有利（強）で前1/3にいて5着以内 ＝ 先行して粘った馬。前有利（強）で後1/3にいて5着以内 ＝ 後方から届いた馬 |
| 順行 | 差し有利系で中・後にいた馬、前有利系で前にいた馬（5着以内） |
| 信頼度 | A＝3着内、B＝4〜5着 |
| 除外 | 障害、通過順が無いレース、6着以下 |
| 注記 | 4角で単独先頭（2馬身以上の差）は「楽逃げの可能性・人間確認」を付ける（本適用の48頭には該当なし） |

レースレベル・タイム・着差の数値は使っていない（羊一様の指示どおり）。

## 4．次走での使い方（案 §4 のまま）

- 逆行A・次走で人気薄 → **ワイド穴として照合**（運勢・ROIのどちらかが支えれば）。
- 逆行A・次走で人気上位 → 人気側比較の材料。**本体で本採用再判定**は能力・運勢・ROI・本シート判定の2系統以上が確認済みの場合のみ。
- 逆行B → **薄め相手として照合**。
- 順行で次走が人気上位 → **過剰人気警戒**（方向性メモ）。
- 必須ゲート（騎手運勢AB／実測ROI／CB・CJ・DA）は変えない。逆行だけで判定語を上げない。
