### 4-3. 何が生き残り、何が落ちたか

**生き残ったもの**

1. **Q1(前不利側)が常に最下位。** 芝13.32% / ダ14.56%（穴×前1/3）。芝ダ別、良馬場別、15-18頭別、前後半別のすべてで例外なし。**最も安定した単一の言明**です。
2. **差(前−後)が前有利側で拡大する。** 芝の穴帯で完全に単調（+7.82→+15.78pt）。ダの本命帯でも単調（+26.56→+52.75pt）。**前有利側の日は、後ろで運ぶことの不利益が倍近くになる。**
3. **後1/3の穴馬は前有利側で半減する。** 混合四分位で 5.55% → 2.91%。断念方向の材料としては最も明瞭です。
4. **ダートの方が信号が強い。** 事前TBと当該レース `flow_r` のPearson相関は ダ 0.2696 / 芝 0.1370（全体 0.2387 [0.1988, 0.2779]、r²=0.057）。

**落ちたもの**

1. **「前有利側の日は前の穴馬がよく走る」の水準単調性。** 芝ダ内では消えます。混合四分位での美しい単調性（14.56→21.10%）は、芝ダの混合が作った見かけです。
2. **ダートの穴帯にQ2/Q4が高くQ1/Q3が低いジグザグ**があり、前後半どちらでも同じ形で再現します（前半 14.35/20.69/14.36/20.78、後半 14.80/28.21/19.19/27.23）。再現するジグザグは偶然と考えにくいのですが、`flow_r` の算出式が未提供のため**原因を診断できません**。→ 列定義要確認。
3. **芝の良馬場・芝の15-18頭では Q4−Q1 のCIが0を含みます**（+3.20 [−2.56, +9.02] / +5.68 [−0.72, +12.19]）。芝で多頭数、つまり穴狙いの主戦場では、水準差は確定していません。

### 4-4. 穴馬が来るかどうかはTBで変わらない

7〜12番人気全体の3着内率は、TB四分位で **9.74 / 10.97 / 10.53 / 9.06%**。単調性なし、CIは相互に重なります。
3連複払戻の中央値は Q1 4,705円 / Q2 6,025円 / Q3 5,390円 / **Q4 4,340円**。前有利側の日は**堅くなります**。

**TBは「荒れるか」を教えません。「どの穴が来るか（前か後か）」だけを教えます。** 前有利側の日は配当が下がるので、穴狙いにとっては**見送り側の情報**として効きます。

| TB適合のみで他ファクター未確認 | **保留論点あり**（TB単独では本採用再判定に上げない） |
| 出走頭数と資料頭数の不一致 / 内外軸が必要な論点 | **人間確認必須** |

TB単独で「本体で本採用再判定」には上げません。依頼書§8の「TB単独で軸確定や断念へ進めない」に従います。
