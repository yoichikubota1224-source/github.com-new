## 2. 六星占術の実装と検証

`scripts/rokusei_unsei.py` として実装し、**自己検証を内蔵**しました(引数なしで実行すると48セルを照合し、不一致があれば終了コード1)。

```
星数     = MOD(対象日のExcelシリアル − DATE(1950,1,1) + 32, 60) + 1
基準位相 = MOD(2 × 星人帯 + (－: −2 / ＋: −1), 12)      星人帯 = 土星0/金星1/火星2/天王星3/木星4/水星5
日運     = サイクル[MOD(MOD(星数,12) + 基準位相, 12)]
サイクル = 種子・緑生・立花・健弱・達成・乱気・再会・財成・安定・陰影・停止・減退
記号(基本) 達成◎◎ / 立花・財成・安定◎ / 種子・緑生・再会○ / 健弱・乱気△ / 陰影・停止・減退×
記号(霊合) 安定◎◎ / 陰影・停止・減退× / それ以外すべて○
```

**検証: 48/48 一致**(2026-09-12 星数26 / 09-13 星数27、24群×2日)。過去日にもそのまま適用できます。

### 3-3. 検定

- **独立性の検定(3着内 × 運勢5区分)**: χ² = **3.09**、df = 4、5%点 9.49 → **独立を棄却できない**。
- **穴帯での直接比較**: 好運勢(◎◎+◎) n=4,793 3着内 9.72% vs 凶運勢(×) n=4,045 3着内 10.11% → **z = −0.61、有意差なし**。複回収の信頼区間も重なります。
- **感度分析**: Tier A+B(要承認8件を含む・n=44,460)でも結論は変わりません(z = −0.63)。

### 3-4. 読み方

| 言えること | 言えないこと |
|---|---|
| **騎手運勢は単独では3着内率に差を生んでいない。** n=41,077 で各区分のCI幅は±1ポイント程度であり、これは「標本不足で検出できない」ではなく「**差があっても1.5ポイント以内**」という上限の提示 | 「運勢は無意味」とまでは言えない。独立を棄却できないことは独立の証明ではない |
| 回収率は好運勢のほうが低く見えるが、**信頼区間が大きく重なり差を確認できない**。1年分では決着しない | 「運勢◎を避けるべき」とは**言えない**。方向は示唆されるが統計的裏づけがない |

**この結果を弱める要因(いずれも効果を薄める向きに働く)**:

- 群の割り当て自体に誤りがありうる。マニュアルv1.0検証レポートが**所属群の競合6件**(森田誠也・今村聖奈・ディー・舟山瑠泉・吉村誠之・河原田菜々)を記録しており、D列は手入力です。割り当て誤りは真の効果を希釈します。
- `木星霊－` `水星霊＋` の2群は騎手リストが**未取得**のため検証に含まれていません。
- **調教師運勢は検証していません**。調教師の星人グループ表が本リポジトリに未収録のためです(既出の申し送り)。
- 本検証は **騎手運勢の単独効果**を測ったものです。ラボの運用は運勢を単独の足切りではなく複数ファクターの一つとして使うため、**交互作用は検証していません**。

## 4. 騎手ROIファクターの遡及検証

look-ahead を避けるため、**各騎乗の評価にはその日より前の実績のみ**を使いました(直近180日・最低50騎乗)。対象 **39,735騎乗**(全体の82.9%)。

### 4-1. 直近の単回収で層別(ラボのROIタグ S=単複どちらか120%以上 に対応)｜穴帯7〜12人気

| 直近180日の単回収 | n | 将来3着内率 | 将来単回収(95%CI) | 将来複回収 |
|---|---:|---:|---|---:|
| 〜50% | 5,161 | 8.84% | **77.2%** [59.0, 95.5] | 67.4% |
| 50〜70% | 3,482 | 10.28% | 66.7% [47.4, 86.0] | 70.2% |
| 70〜90% | 2,579 | 10.16% | 66.6% [45.1, 88.0] | 66.2% |
| 90〜120% | 2,070 | 10.87% | 86.5% [61.4, 111.6] | 72.5% |
| **120%〜** | 2,177 | 10.01% | **63.2%** [42.8, 83.7] | 65.4% |

→ **単調性がありません。** 直近単回収120%以上の層の将来単回収は63.2%で、最下位層(77.2%)より低い。**騎手の回収率は平均へ回帰しており、将来の回収率を予測しません。**

### 4-2. 直近の3着内率で層別｜穴帯7〜12人気

| 直近180日の3着内率 | n | 将来3着内率(95%CI) | 将来単回収(95%CI) | 将来複回収 |
|---|---:|---|---|---:|
| 〜15% | 6,694 | 8.22% [7.58, 8.90] | 55.1% [41.8, 68.3] | 63.8% |
| 15〜20% | 2,799 | 9.40% [8.37, 10.53] | 78.0% [55.5, 100.4] | 63.2% |
| 20〜25% | 2,614 | 11.36% [10.20, 12.64] | 90.4% [64.6, 116.2] | 73.8% |
| 25〜30% | 1,893 | 11.41% [10.06, 12.92] | 78.2% [52.5, 103.9] | 76.2% |
| **30%〜** | 1,469 | **13.14%** [11.51, 14.96] | **100.9%** [67.8, 134.1] | 77.9% |

→ **単調に上昇します。** 将来3着内率は 8.22% → 13.14%(CIは最下位層と非重複)、将来単回収も 55.1% → 100.9%。**最上位層は本検証で唯一、単回収の信頼区間が100%を含みます。**

### 4-3. 読み方

| 所見 | 位置づけ |
|---|---|
| 騎手ファクターとして将来を予測しているのは、**直近ROIではなく直近3着内率** | **保留論点あり**。現行ROIタグ(S=単複どちらか120%以上)は、平均回帰する指標を上位として拾う構造になっている |
| 最上位層(直近3着内率30%以上)の将来単回収 100.9% | **CIは[67.8, 134.1]で100%を含むが、100%を超えているとは言えない**。「break-even を否定できない」であって「プラス収支」ではない |
| 交絡の可能性 | 直近3着内率が高い騎手は良い馬の依頼を受けやすい。穴帯に限っても、帯内で相対的に良い馬に乗っている可能性がある。**「騎手の腕」ではなく「騎乗馬の質」を測っている可能性**は排除できない |
