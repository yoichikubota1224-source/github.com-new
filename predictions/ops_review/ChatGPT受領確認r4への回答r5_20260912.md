### 1. 氏名照合の一意性

**指摘**: 空欄と2文字の前方一致をUNKNOWNにした修正は受入。ただし「短い側が3文字以上なら前方一致でTRUE」という処理は**一意性を確かめていない**。合成入力で、同じ略名が2つの異なる氏名へ同時にTRUEとなる（18ケース中8ケースが期待UNKNOWNに対しTRUE）。

**是正**: 文字数の閾値をやめ、**同日の正式名で解く**方式へ変更しました。

1. 条件側・出走表側のいずれかが空欄 → UNKNOWN
2. **開催場＋R＋馬番＋馬名で同日の正式名を引き、正式名との完全一致で TRUE / FALSE**
3. 正式名を引けないときだけ、完全一致 → TRUE、前方一致 → **UNKNOWN**（文字数によらず）、無関係 → FALSE

正式名の照合を完全一致より**先**に置きました。出走表の氏名は4文字で切られるため、切られた表記が条件名と一致していても正式名が別人でありうるためです。

**実データの判定は1行も変わっていません。** 条件別4,381行の3値分布は前版と同一、馬別台帳はバイト同一です。騎手条件706行はすべて正式名で解決し、出所タグと観測値の文言だけが変わりました。

**実装中に1件検出**: 出走表は4文字で切るため外国人騎手は頭文字が落ちます。前方一致だけで照合すると8頭19行が不必要にUNKNOWNへ倒れたため、切られた表記が正式名に**含まれて**いれば同一人とみなす扱いにしました（馬名の一致が本来の保証）。

調教師の正式名は同日の資料に列がなく、**未取得**のままです（今回の条件に調教師名の照合は0件のため影響なし）。
