## 1. 結論

**方針に賛成します。** 当方がこの5週間で測ってきた数値は、ほぼすべてこの方針を支持する方向に出ています。
とくに「的中率にこだわらない」は、統計的に正しい判断です。

**ただし1点、言葉の整理が必要です。**

> **「的中率を目標にしない」ことと「的中率を推定しない」ことは、別です。**
> 期待値は `P(入着) × オッズ` なので、**P の推定＝入着率の推定が期待値の半分**です。
> 的中率を目標から外すのは正しく、推定から外すことはできません。

そして実測が示している最も重要な点は、**この P の推定に「過去の回収率」を使うと逆に働く**ことです（§5）。

## 2. 期待値の式に分解すると、既存の規定と矛盾しません

「期待値を優先」と「ファクター優先順位でオッズを最下位に置く」は、一見ぶつかります。
期待値はオッズを含むのに、オッズを最下位に置いているからです。**しかし矛盾しません。**

```
期待値 = P（入着確率の自前推定） × オッズ（市場が付けた価格）
```

| 要素 | 何が担うか | 既存規定 |
|---|---|---|
| **P の推定** | **能力＞運勢＞回収率＞展開馬場＞調教＞補強** | ファクター優先順位は**P の推定順序**として正しく機能します |
| **オッズ** | 市場が付けた価格。**P に対する対抗仮説** | 「オッズだけで評価変更しない」「オッズは荒れ判定と売れ過ぎ確認に限定」 |

**既存規定の「オッズを最下位に置く」は、「オッズを P の推定に混ぜない」という意味で読めます。**
これは**循環参照の防止**です。オッズから確率を逆算して P に使うと、
「市場が安い馬を安いと言う」だけの同語反復になり、期待値が構造的に出せません。

> **したがって「期待値を合言葉にする」ことは、既存のファクター優先順位を変更しません。**
> 変わるのは**出口**です。ファクターは P を作るために積み、**最後にオッズと突き合わせて期待値を見る**。
> 固定指示の処理順（1波乱度 → … → 9オッズ → 10限定判定語で仕分け）は、既にこの順序になっています。

### 4-1.【最重要】「過去の回収率が高い」を期待値と読むと、逆に働きます

出所: 同 §4-1（穴帯7〜12人気）

| 直近180日の単回収 | n | 将来3着内率 | **将来単回収** |
|---|---:|---|---|

**直近単回収120%以上の層の将来単回収は 63.2% で、最下位層（77.2%）より低い。**
**騎手の回収率は平均へ回帰しており、将来の回収率を予測していません。**

> **現行のROIタグ（S＝単複どちらか120%以上）は、平均回帰する指標を上位として拾う構造になっています。**
> 「回収率が高い」を期待値の入口に使うと、**期待値の質を下げる方向に働きます**。

### 4-2. 運勢は単独では入着率に差を生んでいません

出所: 同 §運勢の独立性検定

n=**41,077**、3着内 × 運勢5区分で **χ² = 3.09**（df=4・5%点 9.49）→ **独立を棄却できません**。
各区分のCI幅は±1ポイント程度で、これは「標本不足で検出できない」ではなく
**「差があっても3着内率で1.5ポイント以内」という上限の提示**です。

**「運勢は無意味」とは言えません**（独立を棄却できないことは独立の証明ではない）。
ただし**優先順位で2番目に置くだけの単独効果は、現状の実測では確認できていません**。
運勢が効くとすれば**他ファクターとの交互作用**で、それは未測定です。

### 4-3. 展開は単独では回収率に届きません

**穴7-12帯は単勝 67.14〜72.84%** で、無選別（69.3%）とほぼ同じです。

### 4-4. 「卍指数＝期待値」は、現時点では等号で結べません

| 理由 | 実測 |
|---|---|
| **購入方式が未確定** | `roi_method = UNKNOWN` **1,222行**。311行の合算は `Σ(ROI_i×n_i)/Σn_i`（**均等購入前提**）だが、サイト現行既定は**オッズ反比例**。オッズ反比例なら311行は系統的に誤ります |
| **相関は探索的** | 妙味度×複勝ROIの Spearman **+0.6436** は、母集団468行が原表の **TOP系387＋ワースト系81 の両極のみ**で分布中央を含まず、**抽出が説明変数（妙味度）の順位側にかかっています**。TOP系のみでは +0.4987、騎手TOP群159行では複勝 +0.2649・単勝 +0.0713 |
| **標本が独立でない** | 468行の実体は**201エンティティ**。Kish の `m_A = Σm²/n = 4.0513`、`ICC(1)` 単勝0.4002/複勝0.4612 → **DEFF ≈ 2.22/2.41**、**有効標本 ≈ 211/194**。n=468 で有意性・CIを計算できません |
| 集計期間が空欄 | `period_start`/`period_end` が **0/1,222**。`public_tables.csv` の「（2021-2025）」は候補であって確定ではありません |

> **否定材料でもありません。** 「卍＝期待値」は**検証すべき仮説として妥当**です。
> ただし**現状で等号を置くと、購入方式の不確定がそのまま期待値の推定に入ります**。
> 当面は「卍＝期待値の候補指標」に留め、**限定判定語では「保留論点あり」**が正しい位置です。

### 4-5. 5ヶ月・週3〜5Rでは、回収率の信頼区間は決着しません

実測が示すとおり、**n=373 でも単回収のCIは [48, 162]**、n=1,469 でも [67.8, 134.1] です。

> **「5ヶ月結果が出ている」ことと「期待値の設計が正しい」ことは、現状のnでは分離できません。**
> これは方針を否定する材料ではありません。**むしろ逆です。**
> 結果で判定できないからこそ、**プロセス（期待値）で判定するという羊一様の方針が正しい**のです。

## 5.【最重要の提案】優先順位3位「回収率」の中身を入れ替える

**順位は変えません。** 変えるのは3位の**中身**です。

| | 現行 | 提案 |
|---|---|---|
| 3位「回収率」の入口 | **過去の単複回収率**（S＝120%以上） | **過去の3着内率**（穴帯で単調・最上位層の将来単回収100.9%） |
| 実測での挙動 | **平均回帰**（120%以上層 → 将来63.2%） | **単調上昇**（8.22% → 13.14%、将来単回収 55.1% → 100.9%） |

**理由**: 期待値 = P × オッズ の P を推定するのに、**過去の回収率は P の推定量ではありません**。
過去の回収率は「P × 過去のオッズ」の実現値で、**オッズの変動が混入しています**。
だから平均回帰します。一方 **3着内率は P の直接の推定量**です。

> **これが「期待値の質を上げ続ける」ための、実測に基づく最短経路だと考えます。**
> 「回収率ファクター」という名前は残したまま、**入口の指標を回収率から3着内率へ替える**。
> 回収率は**出口**（期待値の評価軸）に置き、**入口には置かない**。

**留保**: この提案は穴帯7〜12人気での実測に基づきます。本命帯・中穴帯では未検証です。
また交絡（騎乗馬の質）が残っています。**採否は本体裁定です。**

## 6. 「単勝10倍なのに20%入着率」への見解

**定義として正しいです。** 10倍 × 20% = 期待値200%。これが期待値の考え方そのものです。

**問題は「20%」をどこから取るかです。** ここが期待値運用の成否を分けます。

| P の推定源 | 循環するか | 実測の水準（穴帯7〜12人気） |
|---|---|---|
| **オッズから逆算した確率** | **循環する** | 使えません。市場価格を確率に変換して市場価格と比べると同語反復になります |
| **次走期待好走馬** | しない | **3着内 18.5%**（5着内 33.5%） |
| **騎手の直近3着内率** | しない | 最上位層 **13.14%** |
| **展開馬エンジン** | しない | **11.70〜12.12%**（対照群10.2%とほぼ同じ） |
| 無選別の帯平均 | — | **10.2%** |

> **現状、独立推定源で20%に最も近いのは次走期待好走馬の18.5%です。**
> 「単勝10倍で20%」を満たす馬を出せる可能性が実測で示されているのは、この1ファクターだけです。
> 展開と騎手3着内率は10%台前半で、**単独では帯平均を大きく超えません**。

**したがって「20%入着率」は、単一ファクターでは届かず、クロスが必要です。** これが§7です。

### 7-1. クロス抽出の出力様式（提案）

**当方が出すのは材料までで、買い目・点数・資金配分は出しません。** 出力はこの形を提案します。

| 列 | 内容 |
|---|---|
| 馬番・馬名 | — |
| `P_推定` | 各独立源の入着率推定（**出所タグ付き**。例 `18.5%［実：次走期待/n=373］`） |
| `P_源の数` | **独立な推定源の数**（同一元データ由来は1と数える） |
| 基準オッズ | 取得時刻を併記 |
| `期待値_下限` | **P の95%CI下限 × オッズ**（点推定ではなく下限で見る） |
| `期待値_点推定` | P点推定 × オッズ |
| **限定判定語** | 本体で本採用再判定 / 保留論点あり / ワイド穴として照合 / 薄め相手として照合 / 軸不可疑い / 断念疑い / 人間確認必須 |
| 不足項目 | [不足]の列名を明示 |

**`期待値_下限` を主に見ることを提案します。** 点推定で見ると、n が小さい馬が上位に来ます。
実測どおり n=373 でもCIは [48, 162] なので、**下限で見なければ「期待値が高い」は n の小ささを拾うだけ**になります。

### 7-2. 二重加点の防止（ガードレールEの実効化）

クロスの最大の失敗は**同じ情報を複数回数えること**です。実測で判明している共通元データ:

- **場集計・距離集計・回り集計の3行は同一のコース別表 `cidx_e` 由来**で、同じ出走を重複して含みます
- 運勢と騎手ROI参考値は**同一の騎手運勢xlsx由来**
- 卍の妙味度と実測ROIは**同一原表の両極リスト由来**

> **`P_源の数` は「独立な源の数」でなければ意味がありません。**
> 上記はいずれも**1と数える**必要があります。

## 8. 持続性のための仕組み ── キャリブレーション記録

**「期待値の質を上げ続ける」には、期待値の推定が当たっていたかを測る仕組みが必要です。**
これは的中率の採点ではなく、**推定器の校正（キャリブレーション）**の測定です。

| 記録する列 | 内容 |
|---|---|
| `EV_帯` | 期待値の推定帯（例 100-150% / 150-200% / 200%〜） |
| `n` | その帯に入った頭数（累積） |
| `実現_3着内率` | 実際の入着率 |
| `実現_単複回収` | 実際の回収率 |
| `P_推定平均` | 推定した P の平均 |
| **`乖離`** | **`実現_3着内率 − P_推定平均`**（これがキャリブレーション誤差） |
| `判定` | n が閾値未満なら **`測定中`**。閾値到達後に初めて評価 |

**この設計の利点**:

1. **的中率を目標にしません。** 測るのは「推定と実現の乖離」であって、当たった数ではありません
2. **`ACCURACY_SCORING = NO` と衝突しません。** 予想の成績を採点するのではなく、**推定器が校正されているかを測る**ためです。ただし**この解釈が線引きとして妥当かは羊一様の裁定事項**です（9/8から未回答の論点）
3. **n が溜まるまで判定を保留できます。** 「測定中」を許すので、5ヶ月でも週3〜5Rでも成立します
4. **どのファクターが期待値の質を上げたかが分かります。** 乖離が縮んだ源が効いた源です

> **これが「期待値をアップデートし続ける」の実装だと考えます。**
> 回収率は最終の答え合わせに置き、**日々の判断は乖離で見る**。

## 9. 荒れレース選定・穴馬抽出との関係

羊一様の「同時に期待値をアップデートし続けなければ持続的な結果は出せない」というご推測に**同意します。**
実測がその理由を示しています。

| 観点 | 実測 |
|---|---|
| 荒れ選定は**入口の絞り込み**として機能 | 8/16は35R → 選定5R。全頭分析が478頭 → 72頭で**85%減** |
| ただし**選定だけでは期待値は上がらない** | 無選別の7〜12人気帯は単回収 **73.1%**。帯を選んだだけでは100%に届きません |
| **期待値が入って初めて超える** | 次走期待で選ぶと **104.9%**（ただしCI [48,162]） |
| 荒れ選定側の弱点 | SDS/波乱度・1番人気信頼度が **478行全空欄**、EP黄金律8/16版が未生成 → **代替指標で稼働**。テクニカル6の定義書は棚卸し215件に不在 |

> **荒れ選定は「期待値が出やすい母集団に絞る」工程で、期待値そのものではありません。**
> 両方が必要というご推測は、実測と整合します。

## 10. 5ヶ月の結果について

**当方は5ヶ月の結果を検証・採点していません。** `ACCURACY_SCORING = NO` を維持します。
「結果が出ている」というご認識を否定も肯定もしません。

**率直に申し上げると、現状のnでは肯定も否定もできません。** §4-5のとおりです。
ただしこれは**方針への反対材料ではありません**。結果で判定できない期間が長いことは、
**プロセスで判定する設計の必要性**をむしろ強めます。

**もし5ヶ月の実データ（対象R・馬番・基準オッズ・結果）をいただけるなら**、
採点ではなく**§8のキャリブレーション表を遡及で埋める**ことはできます。
それは「当たったか」ではなく「推定と実現がどれだけ離れていたか」の記録です。**ご指示があれば設計します。**
