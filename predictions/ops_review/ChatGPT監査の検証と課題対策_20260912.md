## 5. 対策として実装したもの

説明ではなく動くものを置きました。**`scripts/ledger.py`（判定台帳の生成）と `scripts/ledger_tests.py`（受入テスト）**です。
ルール表の条件文・回収率・標本数はリポジトリ外のファイルに置き、スクリプトは環境変数でそれを参照します（publicリポジトリへ書籍由来の内容を置かないため）。

### 5-1. 判定台帳の設計

従来の抽出スクリプトは「該当馬リスト」を出していました。台帳は**単位を変えます**。

| 変えた点 | 従来 | 台帳 |
|---|---|---|
| 出力の単位 | 馬ごとの集約結果 | **馬 × ルール × 条件** の1行 |
| 判定値 | 該当／非該当 | **TRUE / FALSE / UNKNOWN の3値**。UNKNOWNをFALSEに落とさない |
| 根拠 | 文章 | **必要条件・観測値・単位・出所タグ・理由コード**を全行に持つ |
| 未実装 | 沈黙して「該当なし」 | **UNKNOWN(`UNK_NOT_IMPLEMENTED`)**。「該当0」と別物として出す |
| 明確な不成立 | 表から消える | **条件別台帳に全行残す**（監査可能にする） |
| 適用範囲 | 該当馬0と混同 | **「当日に該当コースなし」を別ログに分離** |
| 中N週 | 経過週数（+1ずれ） | **JRA定義**。連闘は数値ではなく「連闘」 |
| 回収率 | 列内で倍率と百分率が混在 | 倍率で保持し、出力時に一度だけ変換 |

### 5-3. 理由コード

UNKNOWN を「なんとなく分からない」で終わらせないため、理由を分類しました。ChatGPT が A06 で要求した区別（評価関数あり／実行済み／該当0／非該当／入力不足／対象外）はこれで表現します。

| 理由コード | 意味 | 行数 |
|---|---|---:|
| `UNK_NO_ALLOWANCE_COLUMN_LIKELY_NONE` | 減量記号の欄が存在しない。斤量差は基準以下（＝減量なしと整合するが確定しない） | 100 |
| `UNK_NOT_FIXED_WEIGHT_RACE` | 定量戦でないため斤量差から基準が読めない（ハンデ・別定） | 65 |
| `UNK_DEF_AMBIGUOUS_FINISH` | 前走着順の「○着以下」の語義が二義。**両方の読みの結果を観測値に残す** | 53 |
| `UNK_NO_ALLOWANCE_COLUMN_LIKELY_REDUCED` | 同上。斤量差は基準より軽い（＝減量の疑い） | 33 |
| `UNK_SIRELINE_NOT_RESOLVED` | 父系の合議が未実施 | 28 |
| `UNK_DEF_AMBIGUOUS_CENTRAL` | 「中央場所」の語義が二義 | 26 |
| `UNK_PREV_ROW_OUT_OF_WINDOW` | 前走行が収録窓の外（**入力不足**） | 16 |
| `UNK_PREV_CORNER_ABSENT` | 前走の通過順が空欄 | 4 |
| `UNK_PREV_3F_ABSENT` | 前走の上がり3F順位が引けない | 1 |

FALSE 側も同様に分類しています。とくに **`FALSE_DEBUT_NO_PREV_RACE`（217行）** は「新馬のため前走がない＝条件は充足不能」であり、`UNK_PREV_ROW_OUT_OF_WINDOW`（入力不足）とは別物として扱います。
