手順と検査の記録です。**馬名・印・オッズの実数・回収率の数値は含めません**（それらは私用の引渡しパックにのみ置きます）。外部からの新規データ取得はしていません。**最終印・軸・買い目・点数・資金配分・最終採否は確定していません。**

## 1. できる検証が「不能」とされていました

受領済みの「荒れ傾向分析CSV 過去1年」に、**着順・人気・確定単勝オッズ・単勝/複勝/3連複/3連単の払戻・馬体重**が全レース分入っています。収録期間は前年9月から当年9月上旬までです。

ところが過去の結果分析は、当時の取得手段（結果ファイルの欠落・PDFの収録漏れ）を理由に、

- ある開催日の結果分析は「1レースぶんしか結果がなく、系統的な分析は不能」
- 別の開催日の結果分析は「PDFが奇数レースのみ収録で、5レースは[不足]」

としていました。**いずれも受領済み資産で埋められます。** 前者は全36レース・印253件の突合を完了し、後者は5レースの確定結果を補完しました。**受領資産の棚卸しが追いついていなかったこと**が原因です。

## 2. 印と着順の突合（1開催日・全36レース）

予想の印は当時の出力の転記で、当方が新たに生成したものではありません。予想馬名と結果馬名の不一致は0、単勝払戻と確定オッズの整合も0件の不一致でした。

**3着内率は印の序列どおりに単調**でした。順位付けの能力はあります。**一方で単勝回収率は序列が逆転**し、本命の回収率が最も低く、最下位の印が最も高いという形でした。本命は1着と2着がほぼ同数で、勝ち切れていません。

確信度の高いレースの本命は、3着内率・単勝回収率ともに確信度の低いレースを上回りました。**ただし母数が1桁で、偶然の範囲です。単日・小標本でルールは昇格させません。**

荒れ候補として選定したレースと非候補で、実際に荒れた割合の差は小さく、**母数が1桁で判定できません**。「荒れ」の原典定義は未取得で、当方の暫定定義を使っています。

## 3. 記載値の照合（6日分＋他AIの資料）— 誤りの有無は取得経路で決まる

過去の結果分析6日分と、他AIが作成した振り返り資料について、**合計177項目を一次データと照合し、23項目が一致しませんでした。**

| 結果の取得経路 | 不一致 |
|---|---|
| 結果PDFからテキスト抽出（文字化けなし）＋払戻欄で二重確認 | **0** |
| 結果PDFの該当レース表で二重確認（他AIによる修正版） | **0** |
| 結果PDFを**画像化してOCR**＋払戻欄で二重確認 | **多数** |
| web（レース結果ページ）から取得 | 毎回少数 |
| **自らの過去レポートからの二次引用** | 伝播 |

### 画像OCRの回の誤り方が構造を示しています

**着順・馬番・馬名は全件正しく、誤っていたのは人気と「2着以下の単勝オッズ」だけ**でした。1着の単勝オッズは全レース正しい。理由は、**1着の単勝は払戻欄で裏取りできるが、人気と2着以下の単勝オッズは払戻欄に無く裏取りできない**ためです。「払戻欄で二重確認」という手順は正しいものの、**裏取りできない項目には効きません**。

## 4. 結論に影響した誤り

数値の誤りそのものより、**その数値を根拠に確定ルールへ格上げしている**ことが問題です。2件の格上げについて、根拠事例の人気が実測と食い違っていました。

- ある格上げの根拠5例のうち**2例は人気薄ではありませんでした**（別の1例は逆にもっと人気薄で、主張を強めます）。
- 別の格上げで「白眉」とした事例の勝ち馬は、**人気薄ではなく1番人気**でした。同じ日の別レースでは**1番人気と2番人気が入れ替わって**おり、そこから導いた教訓の中身が変わります。

**この2つの格上げは根拠の再点検が必要です。** ルール自体が否定されたわけではなく、**その事例が根拠にならない**という意味です。

また、3着同着があったレースで、**同着の1頭と2通りある3連複払戻の片方が記載から落ちて**いました。決着が堅かったという結論は変わりません。

## 5. 他AIの照合能力について

6日分のうち1日は、他AIが当方の初版の**9件の誤り**（馬名・騎手・人気とオッズ・表現矛盾）を指摘して修正した版です。**その修正後の値を照合して、不一致0**でした。**照合能力そのものは正確に機能していました。** 直近の資料で出た1件の誤りは、**一次データに当たらず自らの過去レポートを引用した**ことによるものです。

## 6. 課題・対策

| # | 課題 | 対策 |
|---|---|---|
| W-1 | 画像OCRの数値のうち、払戻欄で裏取りできない項目が検証されていない | 人気は**単勝オッズの昇順から機械的に再構成**して照合する。OCR値を人気の根拠にしない |
| W-2 | web取得は人気の誤りが毎回出る | 一次データを正とし、webは補助に降格する |
| W-3 | 二次引用で誤りが伝播する | 過去レポートを引用するときは**同時に一次データで照合し、結果を併記**する |
| W-4 | 同着が記載から落ちる | 払戻が複数ある行を**機械検出**して必ず記載する |
| W-5 | 誤った数値を根拠に確定ルールへ格上げしている | 格上げ前に根拠事例を一次データで照合する。**該当2件は再点検** |
| W-6 | 「[不足]」の判定が受領資産の棚卸し前に行われている | 資料受領時に「何が検証できるか」一覧を更新する |
| W-7 | 本命の3着内率は高いが単勝回収率が最低 | 券種の割り当てを本体で再判定する（本命は複勝・ワイド側、単勝は下位印の帯で検討） |

## 7. 次にできること

今回検証したのは**過去の結果分析の記載値**です。**予想そのもの（印と着順の突合）は6日分すべて同じ方法でできます。** そこまで積めば本命の母数が現在の約6倍になり、§2で見えた「3着内率は単調だが単勝回収率は逆転」が偶然かどうかを判定できる規模になります。

**ACCURACY_SCORING は継続中で、本書は正式な精度スコアではありません。** 母数と定義を併記し、単日・小標本であることを明記しています。
