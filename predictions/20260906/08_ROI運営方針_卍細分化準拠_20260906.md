## 1. 卍の細分化から当方が受け継いでいる設計

### 1-1. 3層構造

| 層 | 中身 | 位置づけ |
|---|---|---|
| 層1 | 卍・**全体**妙味度（騎手・種牡馬・調教師） | 既に当方が保有。統合指数のβ項に内包済み |
| 層2 | 卍・**条件別**（馬場状態／回り／内外ほか） | 別軸。層1と足し合わせない |
| 層3 | 5年**細分化ROIグリッド**（競馬場×芝ダ／距離帯／クラス／芝ダ） | **卍の細分化を当方データへ移した本体** |

### 1-2. 計算式（当方実装・[実]）

```
μ  = 母集団平均ROI（出走数加重）
基礎ROI = μ + n/(n+K_base) × (生ROI − μ)          K_base = 100
条件ROI = 基礎ROI + n/(n+K_ctx) × (条件生ROI − 基礎ROI)   K_ctx = 75
ROI指数 = 100 × 縮約後ROI / μ
統合指数 = 100 + α×(ROI指数 − 100) + β×(卍妙味度 − 100)   α=0.6 / β=0.4
```

**この経験ベイズ縮約が、卍の細分化を「小標本で暴れさせずに」使うための中核です。**
条件のnが0なら条件指数は基礎指数に戻り、914件すべてで一致を確認済み＝[実]。

### 1-3. ★ 中立点は100ではなく約79です［実］

当方の実測した母集団平均ROI（出走数加重）は 騎手78.6／種牡馬79.1／厩舎78.3（単勝）。
**JRA控除率があるため「ROI 100%が中立」ではありません。**指数100＝母集団平均＝実ROI約79%です。
初版は寄せ先を100に置いて指数が88〜91中心に偏り、μアンカーへ修正しました。

## 2. ⚠ 使うときの制約（既存ガードレールの要点）

| # | 制約 | 根拠 |
|---|---|---|
| A | **細分化ROIを独立トップファクターにしない。**「③回収率」配下の小見出しとして出す | ファクター優先順位 能力>運勢>回収率>展開馬場>調教>補強>オッズ を変えない |
| B | 統合指数が高いことを理由に能力・運勢より先に結論を書かない。**低いことを理由に能力上位馬を消さない** | 消し禁止 |
| C | **レース選定ゲートを先に通す。**「指数が高い騎手がいるからこのレースを選ぶ」は禁止 | 選定→参照の順序 |
| D | 統合指数のみを根拠にした行を作らない。必ず他ファクターと併記 | — |
| E | **卍の二重加点禁止。**統合指数はROIと卍を既に1つに畳んである。畳んだ後にROIや卍全体妙味度を別項目で再加点しない | ROI×卍の相関 +0.54〜+0.72＝独立でない |
| F | **NO_SAMPLE(n=0)を減点しない。**「単回=0／複回=0」は未出走であって0%ではない | [不足]を0に変換しない |
| G | 当年ROIを単独で強採用しない（5年n≥100×当年n≥30の1,529組で単回Pearson 0.06＝ほぼ無相関） | — |
| H | **`index` 単独でのソート・上位抽出を禁止。**必ず `n_starts` を併用（推奨 n≥30 で足切り＋n併記） | index≥110 の2,089行のうち n<10 が348行。最悪例は n=2 で指数230 |

**購入ゲートとの関係**: 統合指数は「③回収率ファクター内部の解像度」であり、**購入可否とは無関係**です。
購入ゲートへの接続はAR3段階判定（n≥100・下側5%CI≥100・上位5的中除外後も≥100・BH-FDR・期間別安定）を通った条件のみで、**現時点でJRA/NAR単複とも通過0件**＝[実]。
