## 1. 方法（当方が自分で計算した手順）

1. `toukei_20260906.json` から `ba+r+馬番` を主キーに484頭を取り出す［実］。
2. **レース内で** コンピ指数・IDM・ウマトク指数・タイム指数4本（最高／5走平均／距離／コース）をそれぞれ z 標準化（そのレースで値を持つ馬のみ、母標準偏差）［実］。
3. IDMとウマトクが実質同一軸（§2 ρ=0.938）のため2軸に圧縮: `S = ( z(コンピ) + (z(IDM)+z(ウマトク))/2 ) / 2`［推:重複排除］。**全484頭に欠測なく計算できる唯一の序列**。
4. タイム指数 `zT = 保有する4本のzの平均`。`B = (S + zT)/2`（タイム50%）と `A4 = (3·A3 + zT)/4`（タイム25%）で感度を見る。**zTが無い馬は B を計算しない**（0に置換しない）［実］。
5. 断層 = S降順の隣接差の最大値。`÷平均` = 最大隣接差／平均隣接差。型: 1〜2位の後=頭部、3〜4位=上位、末尾2つ=尾部（=頭部平坦）、それ以外=中位［実］。
6. 乖離 = 基準人気 − 能力順位（**＋＝能力序列が市場序列より上**）。乖離S（3指数）・乖離B（タイム50%）・乖離C/I/U/T（単指数）を併記［実］。
7. 頑健性: 順位平均法（3指数の順位の単純平均）でも首位・上位3を出し、Sと食い違うRを明示［実］。

⚠ 合成の重みは当方の作業仮説であり正本の規則ではない＝[要確認]。重みを変えても動かない部分と動く部分を分けて示す。
