## 1．考え方（羊一様の指示を当方の言葉で固定）

- 同じデータと同じファクターを同じ順に読めば同じ馬に着き、同じ人たちと払戻を分け合う。主力券種の3連複は払戻率75%であり、多数と同じ読みでは長期の回収率100超は構造的に難しい。
- 差別化は「他人が持たない数字」ではなく「**同じ結果の違う読み**」で作る。市場は着順を見る。着順が隠しているものを読む。
- 着順が隠すものの代表が**流れとの向き**。後方有利の流れで先行して粘った馬、前有利の流れで後方から届いた馬は、着順より内容が良い。これを**逆行好走**と呼び、次走期待好走馬の抽出条件に加える。
- 逆に、流れに乗って好走した馬（**順行好走**）は着順どおりに評価されやすく、次走は過大評価の側に置く。
- 逃げ馬の数はこの物差しの一部。逃げ馬が多く前半が速い中で先行して残った馬は逆行好走、逃げ馬が少なく楽に逃げ切った馬は順行好走。数は当日の消しではなく、**過去走の価値を測る条件**として使う。

## 2．定義（最小限。レースレベル・タイム・上がり比較は使わない）

### 2-1．そのレースの「流れ」（前有利／後有利／中立／不足）
判定の優先順位：
1. **当日TB診断の共通記録**（版つき）があればそれを流用する。別に作らない。
2. なければ **上位入着馬の位置取り**で判定する。3着内3頭のうち、4角で前1/3にいた馬が2頭以上 → 前有利、後1/3にいた馬が2頭以上 → 後有利、それ以外 → 中立。
3. 4角の位置取りが取れないときは脚質表記（逃・先／差・追）で代用し、**「代用」と明記**する。
4. どれも無ければ**不足**とし、順行／逆行を付けない（0や中立に置き換えない）。

補助（判定を変えず、注記に残す）：逃げ候補の頭数と前半の速さ。多数で速ければ後有利側の傍証、単騎で楽なら前有利側の傍証。

### 2-2．本馬の位置取り
4角で 前1/3／中／後1/3。取れなければ脚質表記で代用し明記。

### 2-3．順行／逆行／中立
| 流れ | 本馬の位置取り | 区分 |
|---|---|---|
| 後有利 | 前1/3 | **逆行** |
| 前有利 | 後1/3 | **逆行** |
| 後有利 | 後1/3 | 順行 |
| 前有利 | 前1/3 | 順行 |
| 中立、または位置取りが中 | — | 中立 |
| 不足 | — | 付けない |

### 2-4．対象着順と信頼度
- 3着内で逆行 → 抽出。**信頼度A**。
- 4〜5着で逆行 → 抽出。**信頼度B**。
- 6着以下は対象外（ここを広げると際限がなくなるため。羊一様の「キリがない」に合わせる）。
- 着差・タイム・レースレベルは判定に使わない。着差は表示値のまま注記に残すだけ。

### 2-5．除外
- 楽な単騎逃げで残った馬は順行（逆行にしない）。
- 出遅れ・不利で後方になった馬が届いたケースは、位置取りの理由が展開でないため**中立**とし注記に理由を書く。

## 3．台帳列（既存の監視リストに追加。既存列は変えない）

既存列：由来／馬名／次走日／場R／頭数／基準人気(事前)／確定人気／着順／相対着順／規則区分／帯(確定人気)／出所／注記
追加列（v1.1で採用済みだが未付与の `TRIP_BIAS_LABEL` をここで実装する）：

| 列 | 値 | 出所 |
|---|---|---|
| 好走レース日・場R | 逆行好走したレース | 結果一次取得 |
| 流れ | 前有利／後有利／中立／不足 | §2-1（TB共通記録 or 上位馬の位置取り） |
| 流れの判定根拠 | TB記録の版／上位3頭の位置取り／脚質表記で代用 | 同上 |
| 本馬の位置取り | 前1/3／中／後1/3（代用なら明記） | 4角通過順 or 脚質表記 |
| TRIP_BIAS_LABEL | 逆行／順行／中立 | §2-3 |
| 好走時の着順・人気 | 表示値 | 結果一次取得 |
| 信頼度 | A（3着内）／B（4〜5着） | §2-4 |
| 逃げ候補の頭数（参考） | 事前の脚質「逃」表記の頭数 | STRIDE 提供値 |
| 次走での市場評価 | 次走の基準人気・朝の実売順位 | 当日抽出時に記入 |
| 次走の扱い（限定判定語） | §4 | 当日抽出時に記入 |

## 4．次走での扱い（限定判定語への写像。必須ゲートは従来どおり）

| 台帳の状態 | 当日抽出での扱い |
|---|---|
| 逆行・信頼度A、次走で人気薄 | **ワイド穴として照合**（運勢・ROIのどちらかが支えれば） |
| 逆行・信頼度A、次走で人気上位 | 人気側比較の材料。**本体で本採用再判定**は能力・運勢・ROI・本シート判定の2系統以上が確認済みの場合のみ |
| 逆行・信頼度B | **薄め相手として照合** |
| 順行で次走が人気上位 | **過剰人気警戒**（方向性メモ。判定語ではない） |
| 流れが不足で区分なし | 従来どおりの扱い。逆行加点をしない |

**逆行好走だけで「本体で本採用再判定」を使わない。** 運勢・実測ROI・CB／CJ／DA の必須ゲートは変えない。

## 5．手順（週次）

1. 開催日の結果確定後、各レースの「流れ」を §2-1 で判定して記録する。
2. 掲示板（5着以内）の馬について位置取りと TRIP_BIAS_LABEL を付け、逆行の馬を監視リストへ追加する。
3. 次の出馬表が出たら、監視リストと当日抽出を馬名で突き合わせる（9/14 の課題「監視リストと当日抽出の未接続」の解消手段）。
4. 当日抽出では §4 の写像で限定判定語を付け、市場評価を記入する。
5. 結果後は件数のみ記録する（逆行A／逆行B／順行 別の出走数と3着内数）。精度採点・回収率検証はしない。

## 7．不要とした項目（羊一様の指示により、意図的に入れない）
レースレベル、走破タイム、上がりタイムの比較、着差の数値評価、クラス補正、馬場差補正。これらを足し始めると際限がなく、同じデータの積み上げに戻るため入れない。必要になったときは別案として起票する。
