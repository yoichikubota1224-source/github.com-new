## 3. 4層ラベルの採用(ChatGPT提案に同意)

初版マニュアルは「元レース固定ゲート不足→研究区分HOLD」で、**研究記録と次走購入ゲートが混在**していた。ChatGPT提案の4層分離を採用する:

1. **RESULT_LABEL**: 着順・着差等の客観結果(固定ゲート不要で記録可)
2. **TRIP_BIAS_LABEL**: 個体不利(映像/裁決)と馬場バイアス(TB)を**別々に**記録
3. **RESEARCH_DISPOSITION**: RESEARCH_CORE/CONDITIONAL/HOLD_MISSING/EXCLUDE(研究抽出の結論)
4. **LIVE_GATE_STATUS**: 次走時のAB→AZ:BA→CB→CJ→DA(**次走の予想・購入接続時のみ**適用、不足時HOLD)

これにより、元レースの固定ゲートが未取得でも**研究記録(1〜3層)は残せ**、次走で予想・購入へ接続する瞬間に**4層目を全再取得**する。研究抽出と購入ゲートの混在が解消する。
