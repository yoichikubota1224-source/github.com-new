## 1. 方法（当方が自分で計算した手順）

1. `toukei_20260905.json` から `ba+r+馬番` を主キーに446頭（取消1頭を除く）を取り出す［実］。
2. **レース内で** コンピ指数・IDM・ウマトク指数・タイム指数4本（最高／5走平均／距離／コース）を
   それぞれ z 標準化（母平均・母標準偏差、そのレースで値を持つ馬のみ）［実］。
3. IDMとウマトクが実質同一軸（後述§2）のため、紙面3指数を**2軸に圧縮**して合成:
   `S = ( z(コンピ) + (z(IDM)+z(ウマトク))/2 ) / 2`［推:§2の相関0.942に基づく重複排除］。
   これが**全446頭に対して欠測なく計算できる唯一の序列**である［実］。
4. タイム指数は `zT = そのレースで値を持つタイム指数z の平均`。
   `B = (S + zT)/2`（タイム50%）と `A4 = (3·A3 + zT)/4`（タイム25%、A3は3指数単純平均）の2通りで感度を見る［実］。
5. 断層は S の降順に並べた隣接差 `gap[i]=S[i]-S[i+1]` の最大値。
   `断層z`＝最大隣接差、`÷平均`＝最大隣接差／そのレースの平均隣接差［実］。
6. **[不足]は0に置換しない。** zT が無い馬は B を計算せず「S のみの暫定序列」として保持する［実］。

⚠ **合成の重みは当方の作業仮説であり、正本の規則ではない＝[要確認]。** 本報は重みを変えた2通りを併記し、
   「重みを変えても動かない部分」と「重みで動く部分」を分けて示すことで、重みへの依存を明示する。
