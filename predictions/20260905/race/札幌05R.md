## 4. 係同士の食い違いと、優先順位でどう解いたか

**優先順位：能力 > 運勢 > 回収率 > 展開馬場 > 調教 > 補強 > オッズ。多数決は取らない。**

### 4-1. 【能力 vs 補強】序列の頭は③か②か

| 係 | 主張 | 層 |
|---|---|---|
| K08（⑧指数能力） | **S1位＝③ポーラールート**（2.384）。2位②との差 0.782 | **能力** |
| K07（⑦STRIDE） | **JRDB合計値順位1位＝②ローズファミリー**（+23、2位③と+12） | **補強** |
| K07（同） | ただし **SAV1位＝③**（120、2位⑦と+32）／**信頼度ＡＡ＝③（場内唯一）**／1位一致 **×** | 補強内部で分裂 |

**解き方（多数決ではない）**

1. 規約の優先順位により、**序列の頭は能力係の判定（③）を採る**。
2. 当方の独立再計算でも③が**コンピ1位・ウマトク1位・基準人気1番手・SAV1位・`tenkai`1位**の5系列で首位、
   IDMのみ2位（49 対 45）である＝[実]。②が単独で首位を取るのは **JRDB合計値と IDM の2系列**。
3. K07 自身が §4-1 で「`total_rank` と `sinrai` は別の量を測っており、1つの序列に畳んではならない」と述べ、
   本レースを「合計値1位とSAV1位が別馬の20R」に数えている。**K07の内部でも②単独首位は支持されていない。**
4. ⚠ ただし②の合計値+23 の内訳（ST指数と仕上指数の分解）は当方が生値を持たないため**検証できない＝[不足]**。
   本レースは⑥調教が13/14で[不足]なので、仕上指数側の裏取りもできない。
   **「②の合計値1位は調教指数由来ではないか」という仮説は立てられるが、当方は確認できない。** 断定しない。

⇒ **結論：能力序列の頭部は③、次位が②。両者と3位以下の間に本レース最大の段差（1.019＝平均の4.03倍）がある。
②が JRDB合計値と IDM の2系列だけで首位に立つ事実は、消さずに併記する。** 確信度 **C**（K08準拠。独立成分のタイム指数が丸ごと[不足]）。

### 4-3. 【オッズ】K11の券種方向「連系寄り」は、2つのしきい値の**両方**で紙一重

K11 の作業定義（正本規則ではない＝[推:K11定義]）：

```
3連系寄り : 有効頭数 >= 8.0  または  MULTI_HOLE >= 24%  または (断層一致 = 1/3 かつ ONE_HOLE >= 64%)
```

本レースの実測（当方再計算）＝[実]：

| 入力 | 値 | しきい値 | 余裕 |
|---|---:|---:|---:|
| 有効頭数 | **7.981** | 8.0 | **−0.019（0.24%）** |
| MULTI_HOLE | 16.0% | 24% | −8.0pt |
| 断層一致 | **1/3（該当）** | 1/3 | 0 |
| ONE_HOLE | **63.5%** | 64.0% | **−0.5pt** |

⇒ **「断層一致1/3」の条件は既に満たしており、ONE_HOLE がわずか0.5pt 高ければ3連系寄りに反転する。
同時に、有効頭数が 0.019 高くても反転する。** K11 の適用そのものは正しい（当方の再計算と一致）が、
**この二重の紙一重を K11 は書いていない＝抜け。**

さらに **K02 は本レースの境界感度を max|ΔONE| = 0.5 と算出している**（1頭増えて15頭になればセルが[15,19)へ移り 64.0 になる）＝当方も再現[実]。
**K02 の 0.5pt と K11 のしきい値 64.0% は、突き合わせると「1頭で方向が変わる」ことを意味するが、
2つの報告書のどちらもその接続を書いていない＝係またぎの抜け。**

⇒ **解き方**：オッズは優先順位最下位である。K11の**確信度D**（欠測率100%）を維持したまま、
**方向は「連系寄り（境界上）」としてHOLD**する。数値を書き換えない。買い目・点数には一切変換しない。
参考として、本レースは **ONE_HOLE 63.5% の9レース中、有効頭数が最大（7.981）・上位3内在確率が最小（50.06%）・o5/o1 が最小（2.567）**
＝**9レースの中で最も構造がばらけている**＝[実]。K11 §5-2 の「ONE_HOLEを単一根拠にすると構造が違うレースが同一扱いになる」の実例である。

### 4-4. 【補強／規約】⑤の「0」をめぐる K05・K12 と規約 §0 の衝突

K05・K12 はともに「⑤[不足] 0」と数え、両者は**一致**している。

K05 F-9 の「札幌1種が条文非残存＝検証不能」と、全14頭が前走なしである事実の両方を根拠とする。

### 4-5. 【データ監査】K08 §7 と K08 §8 の内部不整合（§3-4）

同一係の中の食い違いなので優先順位では解けない。**当方は §7（床の警告）を正とし、§8 のレンジ指標を本レースに適用しない。**

### 4-6. 【表記】K01 §5-2 #1 の判定と、K01自身・K02・K05・K11・K13 の「芝1500内」（§3-1）
