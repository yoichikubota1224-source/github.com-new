## 4. 二重加点エクスポージャ(CHK-E)

今回のKindle実データで、二重加点リスクが**現に生きている**ことを局所検証した。

- **全体版(層1)**: 妙味度は Jockey 136件中100超56件(min62/max133)、Sire 698件中218件(max456)、Trainer 185件中79件。この妙味度は統合指数の `manji`(β項)に**既に内包**。→ **CHK-E1/E2**: 統合指数を出した上で同じ卍全体妙味度を別項目に再掲・再加点しない。
- **条件別(層2素材)にも実測ROIが混在**: 単回収率が JockeyCond 183/403・SireCond 112/390・TrainerCond 155/429 で埋まっており、`出所` 列は `実:db-keiba/コース別` 等。つまりこれらは**卍だけでなくdb-keiba実測ROIを同一表に連結済**。→ **CHK-E4**: 統合指数は卍とROIを既に1つに畳んである(相関+0.54〜+0.72)。畳んだ後にROIを別途加点しない。**READMEの警告「卍値と実測ROIを同一根拠として二重加点しないこと」と一致**。
- 条件別のentityは全体版に包含(JockeyCond 100/100・SireCond 112/112・TrainerCond 134/135が全体版に存在)。**同一entityの卍が層1と層2の双方に載るが、CHK-E3の通り「別軸として併用可・ただし卍由来を明記し層1と足し合わせない」**。
- **未解決の機械検査ギャップ**: `sire_manji_independent` は種牡馬側のみ全件False固定。**騎手・厩舎側に同等フラグが無く(M-6)、二重加点の機械検査ができない**。Kindle取込でも解消しない。

## 5. 購入非接続・AR3段階判定(CHK-H群)

- 卍・統合指数は**③回収率ファクター内部の解像度**であり、**購入可否とは無関係**(`PURCHASE_LINK=NO`)。購入ゲート接続はAR3段階判定を通過した条件のみで、**現時点 JRA/NAR 単複とも通過0件**(大井434条件でPROFIT1件・SIGNAL4件のみ)。Kindle取込はこの判定を1件も動かさない。
- **CHK-H1 小標本×高指数**: `index単独ソート・上位抽出は禁止`。必ず `件数(n)` 併用(推奨 n≥30足切り＋n併記)。Kindle条件別も同様に n列を必ず併記。
- **CHK-H3 中立点は79**: μ_win = JOCKEY78.60/SIRE79.06/TRAINER78.28。**「ROI100%が中立」「妙味度100が中立」と説明しない**。控除率下で母集団平均ROI≒79%が指数100。
- **CHK-F NO_SAMPLE非減点**: `件数=0`は未出走であって0%ではない。0/平均/中央値で補完しない。`[不足]`タグを消さない。

## 6. 卍指数の活用確認(現行ルールの要約)

| 問い | 確認結果(ガードレール準拠) |
|---|---|
| 卍は独立ファクターか | **否**。③回収率の配下小見出しのみ(CHK-A1/A2/A3)。ファクター数を増やさない |
| 卍が高い＝買いか | **否**。EV・妙味の断定は越権。`統合指数◯◯以上なので買い`等はNGワード(§5) |
| 処理順は変わるか | **不変**。`能力>運勢>回収率>展開・馬場>調教>補強>オッズ`(CHK-B) |
| 卍で能力上位馬を消せるか | **否**(消し禁止 CHK-B3) |
| 全体版と条件別の卍を両方足すか | **否**。層1と層2を足し合わせない(CHK-E3) |
| 調教師運勢の代替に使えるか | **否**。TRAINER=厩舎回収率であり調教師運勢とは別物。`f_調教師運勢:=1.000固定`は不変(§6) |
| 当年ROIを単独強採用するか | **否**(CHK-G。5年n≥100×当年n≥30で単回Pearson0.06・複回0.13≒無相関) |
| 予測力は実証済か | **否**。期間再現性 JOCKEY+0.06/SIRE+0.03/TRAINER−0.03。Phase1シャドー(記録のみ)限定(CHK-H6) |

→ **卍指数の活用範囲は「材料の精密化」まで**。Kindle取込はこの範囲を1mmも広げない。
