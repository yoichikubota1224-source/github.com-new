# 14 調教データの統計分析 第3報 — 生タイムには情報が無い

```yaml
前報: 12_第1報(918頭の測定) / 13_第2報(C-2判定の検証)
標本: 生ラップと複合指数の両方が揃う 589頭 (8/22+8/23)
STATUS: RESEARCH_DRAFT_3
RULE_PROMOTION: NONE
```

> 第2報で私が提案した修正案(絶対秒数の閾値をコース内相対位置に置き換える)を検証した。
> **結果は「効果ゼロ」だった。** 提案は取り下げる。
> ただしその過程で、調教データの価値がどこにあるのかが**同一標本の対照実験ではっきりした**。

---

## 1. 第2報の提案は棄却する

第2報で次のように提案した。

```
現行: 終い1F 11秒台 → A3          (坂路0.3% / ウッド50.4%)
案 : 終い1F がそのコースの上位X% → A3   (坂路もウッドも定義上X%)
```

コース内パーセンタイルで層別した589頭の結果:

| コース内で速い順 | n | 3着内率 | 95%CI |
|---|---:|---:|---|
| 上位10% | 137 | 25.5% | [19.0, 33.4] |
| 上位1/3 | 376 | 23.9% | [19.9, 28.5] |
| 中位1/3 | 155 | **17.4%** | [12.3, 24.2] |
| 下位1/3 | 58 | **24.1%** | [15.0, 36.5] |

**単調ですらない。** 中位が最も低く、下位が中位を上回る。信頼区間も全て重なる。

コース別に分けると、坂路は勾配があるように見える(26.1% / 20.0% / 7.7%)が、**ウッドは逆向き**(19.8% / 15.3% / 28.9%)。方向が一致しない。

人気帯で統制しても同じで、7〜12人気では 上位1/3 10.6% / 中位1/3 15.3% / 下位1/3 8.7% と非単調である。

**コース正規化は問題を解決しなかった。** 絶対閾値がコース依存だという第2報の指摘自体は正しいが、正規化しても情報は出てこない。

---

## 2. 決定的な対照実験 — 同じ455頭で、生タイムと複合指数を並べた

生ラップと複合指数(スライド競馬新聞の`調教指数`)の**両方が揃う馬に限定**し、4人気以下(455頭)で同じ切り方をした。

### A. 生タイム(コース内 終い1Fパーセンタイル)

| | n | 3着内率 | 95%CI |
|---|---:|---:|---|
| 上位+中位2/3 | 408 | 15.2% | [12.0, 19.0] |
| 下位1/3 | 47 | 14.9% | [7.4, 27.7] |

**Fisher p = 1.0000。差が完全にゼロ。**

### B. 複合指数(調教指数のレース内順位)

| | n | 3着内率 | 95%CI |
|---|---:|---:|---|
| 上位+中位2/3 | 252 | **20.2%** | [15.7, 25.6] |
| 下位1/3 | 203 | **8.9%** | [5.7, 13.6] |

**Fisher p = 0.0009。信頼区間が完全に分離。**

### そして両者はほとんど別物を測っている

**生タイム順位 と 複合指数順位 の相関 r = 0.229。**

同じ馬・同じ日・同じ調教を見ているのに、順位の一致度は低い。
複合指数は時計以外の情報(コース・馬場・相手・その馬自身の過去との比較・負荷)を織り込んでいるためと考えられる。

## 3. 理論(第3稿)

前2報と本報を通して、次のように整理する。

> ### 調教の生タイムは、着順に対する情報を持たない。
> **コース差を正規化しても出てこない(p=1.0000)。**
>
> ### 情報を持つのは「時計を文脈に置いて評価した複合指数」であり、
> ### しかもその上位帯ではなく、下位帯にある。
> **複合指数の下位1/3だけが、人気を統制しても残る(p=0.0009)。**
>
> ### すなわち調教は「速い＝走る」を測る道具ではなく、
> ### 「仕上がっていない」を検出する道具である。

### この理論が説明すること

| 観測 | 説明 |
|---|---|
| 坂路/ウッド/併用の種別に差が無い(第1報) | 種別は時計の水準を変えるだけで、文脈評価には寄与しない |
| C-2のA3が機能しない(第2報) | A3は生タイムの絶対閾値。生タイムには情報が無いのだから当然 |
| 「加速＝良い」が逆向き(第2報) | 加速も生ラップの形状であり、同じく情報を持たない |
| コース正規化も効かない(本報) | 正規化しても生タイムは生タイムのまま |
| 複合指数の下位1/3だけ効く(第1報・本報) | 文脈評価が「明らかに足りていない」を拾えている |

### この理論から導かれる実務上の含意

1. **調教の生タイム(4F時計・終いハロン・加速幅)から特徴量を作らない。** 効かないことが2つの独立した切り方で確認された
2. **複合指数は使う。ただし加点ではなく、下位帯のスクリーンとして使う**
3. **C-2のA3/A2/A1/Bという段階評価は、設計思想(速い＝良い)の時点で情報が無い軸に乗っている**

## 4. それでも今回は何も変更しない

| 理由 | 内容 |
|---|---|
| 標本 | 2開催日。スコア重み変更の昇格条件(5開催日以上)を満たさない |
| 「消し」への転用は慎重に | 下位帯スクリーンは実質「消し」である。運勢×を消し根拠にしないのと同じ慎重さが要る |
| 穴馬帯単独では未確立 | 第1報で7〜12人気単独は p=0.10。最も使いたい帯でまだ確立していない |
| 交絡の残留 | 複合指数と人気の相関は r=0.683。帯内の残留交絡を完全には除けていない |

`RULE_PROMOTION: NONE`。調教A3の+1.5も、下位帯スクリーンも、今回は入れない。

## 5. 第4報でやること

### 検証すべきこと

1. **複合指数の下位帯スクリーンを、5開催日まで積む。** 特に7〜12人気帯単独で確立するか
2. **残留交絡の除去** — 人気だけでなくコンピ・IDM等の能力指数も統制して、複合指数に固有の寄与が残るか
3. **複合指数の中身の分解** — スライドの`調教指数`が何を織り込んでいるかは不明。`仕上指数`との差、`最終追切`の指数値との関係を見る
4. 8/16の調教データが入手できれば3日に拡張

### 検証しないと決めたこと

**生タイム由来の特徴量(4F時計・終いハロン・加速幅・コース正規化版)は、これ以上追わない。**
2つの独立した切り方(絶対閾値・コース内相対)で、いずれも情報が出なかった。第4報以降の探索対象から外す。

### 依然として[不足]

**併走/単走・相手馬・馬なり/一杯・先着/遅れ・調教時の馬場状態・中間の本数。**
坂路CSV/ウッドCSVの該当列は全行空欄。

⚠ ただし本報の結果は、**この[不足]がむしろ本丸である可能性**を示している。
生タイムに情報が無く複合指数にあるということは、**価値は「時計」ではなく「文脈」の側にある**ということである。
併走の有無・相手との着差・負荷の強度は、まさにその文脈情報にあたる。**取得できれば最も効く可能性がある。**
