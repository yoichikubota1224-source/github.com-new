## 結論(先に3行)

1. **CHAは現在も実在する提供物である**[実]。仕様書が公開配信されている(`/program/Cha/cha_doc.txt` HTTP 200・4,778B・第1版c)。
2. **CHAの可否は「プランの違い」では決まらない可能性が高い**[推:料金ページに掲載のコースは2つだけで、差分は「コメント直前情報(パドック・返し馬)」のみ。データ会員という別建てのコースが存在しない]。

## 2. CHAは「JRDBデータパック」に同梱されている可能性が高い [推]

公開ページ `https://jrdb.com/data_introduction/`(HTTP 200・43,771B)の**データ仕様一覧**を全行確認した。

- 「前日情報系」テーブルの行は**2行のみ**: `JRDBデータパック（JRDB）` と `JRDB競走馬データ（KYI）`。
- テーブル直下に注記: **「※ KKAはJRDBパックに同梱」**。
- **CHA・CYBは、この一覧のどのテーブルにも単独行として存在しない**[実]。

一方、同ページの**データ連携図**(mermaid)では、前日データを表す `previous` サブグラフの中に4つが並列に置かれている[実]:

```
subgraph previous[前日データ]
  D["=== 競走馬データ ===" ]        ← KYI
  H["=== 情報データ ===" ]          ← KKA(パック同梱と明記あり)
  L["=== 調教分析データ ===" ]      ← CYB
  M["=== 調教本追切データ ===" ]    ← CHA
end
```

**KKAと同じ扱い(=一覧に単独行が無く、連携図には載る)をされているのがCHA・CYBである。**
KKAには「パック同梱」の明記があるのだから、同じ位置にあるCHA・CYBもパック同梱と読むのが自然である。

ただし**これは[推]であって[実]ではない**。理由は、パックの中身を列挙した一次資料が公開されていないため:

- 「JRDBデータパック」行の仕様リンクは `href="#"` の**空リンク**で、遷移先が存在しない[実]。
- `/program/Jrdb/jrdb_doc.txt` → **HTTP 404**[実]。
- `/program/` → **HTTP 403**(ディレクトリ一覧不可)、`/sitemap.html` → **HTTP 404**[実]。

**[不足]を「同梱されている」と断定しない。** §5の確認を経てから[実]に格上げする。

## 3. 料金プランは2つだけで、差分は調教データではない [実]

## 4. 外部からの推定は原理的に不可能である [実]

**認証は行わない。** 羊一様の資格情報を当方が扱う必要はなく、扱うべきでもない。§5はすべて羊一様の手元で完結する形にしてある。

## 7. CHAが入ると何が変わるか — 第2〜4報の欠陥を直接埋める

「次に繋がるように」とのご指示に対し、**CHAを取りに行く価値**を、これまでに測った失敗と対応づけて述べる。

第2〜4報で判明していた壁は次の3つだった:

| # | これまでの所見 | 原因(当方の見立て) |
|---|---|---|
| ① | 追切の**生タイムは情報を持たない**(終い1F、コース正規化後も **p=1.0000**) | 生タイムは**馬場差**と**通った位置**の補正が無い |
| ② | C-2判定のA3は**「ウッドで追った」ことの言い換え**(11秒台の出現率 坂路0.3% / ウッド50.4%) | コース種別が交絡し、タイムの意味がコース間で比較不能 |
| ③ | **「加速=良い」が全人気帯で逆**に出る | 同上。加速の判定自体が非補正タイムの差分 |

**CHAはこの3つすべての直接の解になる**[実:仕様書記載事項]。

| CHAの項目 | 現在保有しているか | ①②③への効き |
|---|---|---|
| **テンＦ指数 / 中間Ｆ指数 / 終いＦ指数**(各3桁) | **無し** | 仕様書に「**当日の馬場差、通った位置で補正されています**」と明記。**①②③の交絡をJRDB側で除去済みの量** |
| テンＦ / 中間Ｆ / 終いＦ(生タイム・3分割) | 無し(終い1Fのみ間接的) | 区間構造そのものが取れる |
| 追切指数 | 相当品あり(調教指数) | 突合による検証材料 |
| **追切種類**(1:一杯 / 2:強目 / 3:馬なり) | **無し** | 「馬なりでこの時計」の識別。厩舎の話の頻出語と直結 |
| **追い状態**(28分類: 終い抑え・鋭く伸び・バテる・掛かる 等) | **無し** | ③の「加速」を、タイム差分ではなく**状態ラベル**で置き換えられる |
| **乗り役**(1:助手 2:調教師 3:**本番騎手** 4:調教騎手 5:見習) | **無し** | 「本番騎手が跨った」を[実]で取れる。現在は厩舎の話の文面頼み |
| 調教コースコード(55種) | 短縮名のみ | ②の層別を正確にできる |
| **併せ馬相手データ**(併せ結果 1:先着/2:同入/3:遅れ・相手の追切種類・年齢・**クラス**) | **無し** | 「**誰に**先着したか」。**厩舎の話で最も引用される要素**で、現在まったく持っていない |
| 調教Ｆ(調教ハロン長) / 回数(本追切当日の追切回数) | 無し | 追切量の正確な測定 |

**特に重視するのは最後の2つ**である。

- 「格上の相手に先着」と「格下に遅れ」は**同じ時計でも意味が正反対**になる。CHAは相手のクラスと年齢を持っているため、**この区別が初めて[実]で測れる**。
- 第4報で唯一生き残った主張は「**調教下位1/3の単回収が低い**(37.3%・CI[5.6, 82.2]・100%を除外)」だった。この指標は現在**非補正タイム由来の合成指数**に依存している。CHAの補正済み指数で組み直せば、**この唯一の生存主張が本物か、交絡の産物かを判定できる**。

### CYBについて(参考・優先度は低い)

CYB仕様と、現在パースしている**スライド競馬新聞CSV**の項目を突き合わせると、**大半が既に手元にある**ことが分かった。

| CYB項目 | スライド競馬新聞CSVの対応 |
|---|---|
| 追切指数 / 仕上指数 | 調教指数 / 仕上指数 **(あり)** |
| 一週前追切指数 / 一週前追切コース | 1週前追切「NN(コース)」 **(あり)** |
| 調教コース種別・種類(坂/Ｗ/ダ/芝/プ/障/ポ) | 調教パターン「坂路/コース/併用」 **(粗いがあり)** |
| 調教重点(1:テン 2:中間 3:終い 4:平均) | 調教パターン「終い重点/テン重点/中重点/平均」 **(あり)** |
| **調教量評価(A/B/C/D)** | **無し** |
| **仕上指数変化** | **無し** |
| **調教評価(1:◎ 2:○ 3:△)** | **無し** |
| **調教コメント(全角40文字)** | **無し** |

→ **現在使っているスライド競馬新聞の調教欄は、実質的にCYBの描画物である**[推:項目が1対1に対応するため]。
CYBを追加で取っても増えるのは4項目(量評価・変化・評価・コメント)にとどまる。
**取りに行く優先順位は CHA ≫ CYB。** CHAは持っていない軸(区間指数・追切種類・追い状態・乗り役・併せ相手)を丸ごと足すが、CYBは既存の増補にとどまる。

> なお CYB仕様書には既知の不具合が明記されている: 「追切指数」の3byteは仕様上右詰めが正だが**左詰めで出力されている**(版数変更CYCで修正予定)。パーサを書く際は右詰め前提にしないこと。

## 8. 判明したこと / 判明しなかったこと

**判明した(一次情報)**

- CHA・CYBは現行の提供物であり、仕様書が公開されている(200)。仕様・コード表とも取得・保存済み。
- 料金コースは2つだけで、差分は「コメント直前情報」のみ。データ専用コースは存在しない。
- 会員エリアは実在パスと架空パスが同一応答のため、外部調査は原理的に打ち止め。
- 現行パイプラインはHTML経由であり、固定長データは一度も取得していない。

**判明しなかった(=[不足])**

- **現在の契約でCHAをダウンロードできるか。** — §6のいずれかで決着する。
- **JRDBデータパックの正確な内容一覧。** — 公開資料が存在しない。§6案Aで同時に解消できる。
- 会員向けデータ配布ディレクトリの実際のURL。

**やらなかったこと(意図的)**

- 会員エリアへの認証。資格情報を当方が扱う必要が無い。
- 認証回避・パス探索の類。§4のとおり情報が得られない上、行うべきでない。
- 「[不足]だから含まれない」という変換。§5のとおり、使っていないことと契約に無いことは別である。

## 9. 次の一手

CHAが利用可能と判明した場合、**調教データの統計分析 第5報**として次を実施する(実施は判明後):

1. CHAのパーサ作成(64BYTE固定長・CP932・レースキー+馬番で結合)。仕様書とコード表はリポジトリに揃っている。
2. **終いＦ指数**(馬場差・位置補正済み)で第2報を再実行 — 生タイムのp=1.0000が補正後も維持されるかを検定する。
3. **併せ馬 先着/遅れ × 相手クラス**の入着率・回収率を、人気帯で層別して測る。
4. 第4報で唯一生き残った「調教下位1/3の単回収 37.3%」を、補正済み指数で組み直して再検証する。
5. **乗り役=本番騎手**フラグと、厩舎の話の記述との一致率を測る(文面依存からの脱却)。

利用不可と判明した場合は、上記2〜5は**[不足]のまま据え置く**。代替として非補正タイムを加工して埋めることはしない — 第2報・第3報で、それが機能しないことを既に測定済みであるため。
