```yaml

前提: 11_ChatGPT見解の検証と実購入台帳_20260823.md で台帳を新設済み。本書はそれを構造化し、
      算出できる指標を先に確定させる
STATUS: LEDGER_STRUCTURED / 一部[不足]
RULE_PROMOTION: NONE
```

> 総投資額が未共有のため実回収率は出せない。
> **ただし4指標のうち1つは購入データ無しで算出できる。** それを先に出した。

---

## 1. 4指標のうち、いま算出できるもの

ChatGPTが提案した4指標を、算出可否で分けた。

| 指標 | 定義 | 必要なデータ | 状態 |
|---|---|---|---|
| **予想カバー率** | 上位3頭を候補集合に何頭含めたか | **予想と結果のみ** | **算出済み(§2)** |
| 券集合カバー率 | 的中組合せを実際の券に含めたか | 券種・組合せ | **[不足]** |
| 資金捕捉率 | 勝ち筋へどの程度資金を置けたか | 総投資額・1点金額・組合せ | **[不足]** |
| 実回収率 | 払戻 ÷ 実投資額 | 総投資額・総払戻額 | **[不足]** |

**予想カバー率は購入データを一切必要としない。** 先に確定させた。

### ⚠ これは現時点で最も強い層である

これまで測定した各層のリフトを並べる。

| 層 | リフト | 出典 |
|---|---:|---|
| **候補集合(印)** | **1.50〜1.61倍** | **本書** |
| レース選定器(荒れ判定) | 1.1〜1.5倍 | `11` |
| 調教(複合指数) | — (下位帯のみ有意) | `12`〜`15` |

**候補集合の作成は、測定した層の中で最も機能している。**

## 4. 記入をお願いしたい項目

次の5項目が埋まれば、残り3指標がすべて算出できる。

```text
【中京8R】
  総投資額      : ______ 円
  券種          : ______ (例: 3連複 / 3連単 / 馬連 / ワイド ...)
  組合せ        : ______ (例: 11-12-4 の1点 / 11軸-12,4,10 の3点 ...)
  点数          : ______ 点
  1点あたり金額  : ______ 円

【8/23の他レース】
  中京8R以外に購入されたレース: あり / なし
    「あり」の場合、各レースについて上記5項目
```

### 埋まると何が出るか

| 指標 | 算出式 |
|---|---|
| 実回収率 | 総払戻額 ÷ 総投資額。総払戻額 = 純利益 + 総投資額 で復元できる |
| 券集合カバー率 | 的中組合せ(⑪-⑫-④)が実際に買われた組合せに含まれていたか。他レースも同様に判定 |
| 資金捕捉率 | 的中組合せに置かれた金額 ÷ そのレースの総投資額 |

**総投資額さえ分かれば実回収率は出る**(純利益から総払戻額を逆算できるため)。優先度が最も高いのはこの1項目である。
