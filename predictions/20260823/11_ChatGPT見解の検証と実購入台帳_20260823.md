## 3. ⚠ ChatGPTの「能力ゲート」提案は、実データでは部分的にしか支持されない

ChatGPTの課題1対策は「**妙味Ｓ＋運勢◎◎＋調教A3でも、能力帯内で下位なら筆頭にしない**」である。
これを8/22+8/23の**前日7〜12番人気の全365頭**で検証した(総合順位÷出走頭数で能力位置を測る)。

| 母集団 | n | 3着内 | 95%CI | 単回収 |
|---|---:|---|---|---:|
| 7〜12人気の全体 | 365 | 46 (12.6%) | [9.6, 16.4] | 80.2% |
| **能力上位1/2以内** | 91 | 18 (**19.8%**) | [12.9, 29.1] | 114.8% |
| 能力上位1/2より下 | 274 | 28 (**10.2%**) | [7.2, 14.4] | 68.7% |
| 能力上位1/3以内 | 33 | 7 (21.2%) | [10.7, 37.8] | 132.1% |

**帯全体で見れば、能力順位は効いている**(19.8% vs 10.2%・信頼区間がほぼ分離)。ここまではChatGPTの主張どおり。

**しかし、妙味Ｓの馬だけに絞ると能力順位は分離しない。**

| 母集団 | n | 3着内 | 95%CI | 単回収 |
|---|---:|---|---|---:|
| 妙味Ｓ(能力不問) | 68 | 12 (17.6%) | [10.4, 28.4] | 177.9% |
| うち **能力上位1/2** | 46 | 8 (**17.4%**) | [9.1, 30.7] | 85.4% |
| うち **能力下位1/2** | 22 | 4 (**18.2%**) | [7.3, 38.5] | 371.4% |

**17.4% と 18.2% で差がない。** 穴筆頭は妙味Ｓを最大重み(3.0)で選んでいるため、**まさにゲートをかけたい母集団で、そのゲートが効くという証拠がまだ無い**。

### したがって

- 「能力順位を穴馬スコアに加える」方向は**支持される**(帯全体で効いている)
- 「妙味Ｓでも能力下位なら筆頭にしない」という**排除ルールは、現時点では支持されない**
- n=68(46/22分割)で信頼区間が大きく重なる。**否定もできないが、採用の根拠にもならない**

ChatGPTのShadow並走案(A=現行 / B=能力比重up / C=能力上位を必須条件)には賛成する。ただし**Cは「まだ効くと分かっていない条件で候補を捨てる」設計**なので、Shadowで回収率まで見るまで本体には入れない。

## 4. ⚠ 監査不整合の是正 — 「実購入なし」という記録は誤りだった

### 何が起きていたか

本リポジトリの `03_採点_20260822.md` / `07_結果分析_課題対策_20260823.md` / `09_ChatGPT引き渡し_事後監査_20260823.md` / `10_累積成績台帳` は、いずれも

```
operation: 0円Shadow(実購入なし。回収率は「購入していれば」の仮定計算)
PURCHASE_ALLOWED: NO
```

と記録している。**実際には中京8Rで実購入があり、+350,000円の収益が発生していた。**

### 切り分け

| 項目 | 判定 |
|---|---|
| `PURCHASE_ALLOWED: NO` / `purchase_status: PROHIBITED` | **誤りではない**。これはClaude工程が買い目・購入可否を出力してよいかのゲートであり、羊一様ご自身の判断を制約するものではない |
| `実購入なし` | **事実として誤り**。Claudeが知り得なかったためだが、記録としては不正確だった |
| 仮定回収率(◎354.6% 等) | **計算自体は正しい**。ただし「実際には買っていない」という前提注記が誤っていた。**仮定計算である旨は維持する**(実購入の券種・点数とは無関係の数字であるため) |

### 是正方針

`07`・`09`・`10` の本文は**改変しない**(追補方式・Drive登録済み)。本書で訂正を明示し、**台帳を2本に分離**する。

| 台帳 | 内容 | 状態 |
|---|---|---|
| **A. 予想成績台帳** | 全候補・暫定印・**仮定**回収率・0円Shadow | `10_累積成績台帳` が該当。**「実購入なし」の記述のみ本書で訂正** |
| **B. 実購入台帳** | 実際の購入と収支。人間の最終承認記録 | **本書§5で新設** |

## 6. ChatGPTの見解 — 同意する点と、留保する点

### 同意する(実データで支持される)

| 項目 | 根拠 |
|---|---|
| 「荒れる＝穴2頭」は成立しない | §2。3日106Rで穴2頭以上は10.4%、荒れレースでも20.0% |
| 人気帯は**購入時人気**で判定すべき | 中京8Rで前日6/9/8人気 → 確定3/6/7人気と大きく動いた実例あり |
| 穴筆頭が能力帯内で下位に寄っていた | §1。3頭とも総合順位が下位で妙味Ｓ |
| 予想成績と購入成績を分離すべき | §4。分離しないと今回のような不整合が残る |
| 4指標の分離(予想カバー率/券集合カバー率/資金捕捉率/実回収率) | 妥当。ただし下2つは実購入データが揃うまで算出不能 |
| `RULE_PROMOTION = NONE` | 一致。3開催日では昇格条件を満たさない |
| Z1・Z2を次開催からShadow記録に加える | 賛成。**記録の追加であり買い方の指示ではない**ため統治上も問題ない |

### 留保する

**(1) 「新潟6Rの完全捕捉を収益化できなかったのは、明確に買い目変換・資金配分側の問題」— 断定できない。**
ChatGPT自身が `ACTUAL_ROI = NOT_CALCULABLE_WITHOUT_TOTAL_STAKE` と書いている一方で、`PURCHASE_CONVERSION_LAYER = PARTIAL_SUCCESS` と等級を付け、買い方を本文の中心テーマに据えている。**測れないと宣言した層に等級は付けられない。**
新潟6Rを購入されなかったのか、購入されて的中しなかったのか、少額だったのかは**現時点で[不足]**である。羊一様が合理的な理由で見送られた可能性も等しくある。§5が埋まるまで、この層の評価は保留すべきと考える。

**(2) 「能力ゲート」を排除ルールとして実装するのは時期尚早。** §3のとおり、妙味Ｓの内部では能力順位が分離していない。方向性は支持するが、条件として候補を捨てる形にはしない。

**(3) 自己採点88点/100 は指標として扱わない。** 自らが関与した予想を自ら採点した値であり、`10_累積成績台帳` の実測とは別物である。前回の55点/100との比較にも意味はない。

**(4) 「予想は大きく前進」という総括には、標本上の裏付けがない。** 3日累積では全印の回収率信頼区間が100%をまたぎ、◎と○の複勝率も分離していない。中京8Rの結果は**1レース**である。方向性の記録としては価値があるが、システムの前進を示す証拠にはまだなっていない。

**(5) 統治上の線引き。** Claude工程は**買い目・点数・資金配分・購入可否を出力しない**。人気構成ゾーンの集計・実購入の記録・成績の分離は「記録と分析」であり継続するが、「どう買うか」の設計には踏み込まない。ChatGPT見解の「少ない点数で利益へ変換する工程」は、その線の向こう側にある。
