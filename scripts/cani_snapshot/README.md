# Cani `allnews.xlsx` 週次スナップショット

```yaml
PURPOSE: 前向き蓄積（遡及不可）
STORAGE: 本リポジトリ外（Google Drive）のみ
REPO_VISIBILITY: PUBLIC（先方コンテンツのファイル格納・逐語再現を禁止）
PUBLICATION_GATE: 許諾取得まで、当該データから導いた統計値も公開しない
```

## 何をするものか

「Caniの競馬データ研究室」が日次で公開している出馬表Excel（`allnews.xlsx`）を
**週に1本だけ**取得して保管する。取得は**PC新聞のExcel 1本のみ**で、
`total/en/` 配下を36ファイル/週で個別取得する必要はない（同内容がこの1本に入る）。

### なぜ蓄積するのか

| 用途 | 効く[不足] |
|---|---|
| レース単位・馬単位の**選別性能の外部基準線**を得る | [不足]4 |
| レース内で事前スコアが割れる層と、穴が2頭絡む構成の出現率の関係を検定する | [不足]3 |
| 取得元原本をハッシュ付きで保全する（**今後分のみ**） | [不足]2 |

### 重要な前提［実］

- **過去は遡れない。** 毎日上書きでアーカイブが無い。**前向きの積み上げにしかならない**
- 中身は**前日夕方に生成された事前データ**。オッズ・人気・馬体重・当該レース着順の列は**無い**
  （＝未来情報の混入が構造的に起こらない）
- 主キー（対象日＋レース＋馬番）が揃っており、当方データと結合できる

## 保管場所

| 対象 | 置き場所 | 理由 |
|---|---|---|
| `allnews.xlsx` の原本 | **Google Drive**（アーカイブ／`Cani_原本スナップショット`） | 本リポジトリは**公開**。先方コンテンツは置かない |
| 取得の来歴（日時・Last-Modified・バイト数・SHA-256） | 本リポジトリ `analysis/cani_snapshot_manifest.tsv` | ハッシュは**内容ではなく指紋**。再現性の鎖を繋ぐために必要 |

⚠ **原本を本リポジトリへ commit しないこと。** `.gitignore` に登録済み。

## 運用手順（Windows）

`snapshot.ps1` を週1回実行する。手で実行してもよいし、タスクスケジューラに登録してもよい。

```powershell
# 例: ダウンロード先を Drive 同期フォルダにする
powershell -ExecutionPolicy Bypass -File .\snapshot.ps1 -OutDir "G:\マイドライブ\...\Cani_原本スナップショット"
```

スクリプトが行うこと:

1. `HEAD` で `Last-Modified` と `Content-Length` を確認する
2. **前回と `Last-Modified` が同じなら取得しない**（先方サーバへの無駄な負荷をかけない）
3. 取得し、`allnews_<Last-Modifiedの日付>.xlsx` として保存する
4. SHA-256 を計算し、`_manifest.tsv` に1行追記する
5. 取得後に**1秒待つ**

### 実行のたびに当方が行うこと

セッション時に `_manifest.tsv` を受け取り、`analysis/cani_snapshot_manifest.tsv` へ追記する。
欠測週があれば**空欄ではなく `[不足]` として行を立てる**（0で埋めない）。

## 取り扱いの制約［統治］

| 行為 | 可否 | 根拠 |
|---|---|---|
| 個人の閲覧・私的保管 | **可** | 先方は閲覧利用を前提に公開している |
| 原本を本リポジトリへ格納 | **不可** | 公開リポジトリ。無断転載に当たる |
| 集計値・本文を報告書へ転記 | **不可** | 無断引用の禁止＝[実] |
| **このデータから導いた統計値の公開** | **許諾取得まで保留** | 導出統計であっても、先方の指数についての事実を公にすることに変わりはない |
| 着想（分割軸の名前・抽出条件のアルゴリズム）の利用 | **可**（層A） | 数値は当方が16,660Rから再計算する |

⚠ **蓄積は行うが、結論の公開は許諾を待つ。** 両者は別の判断である。
